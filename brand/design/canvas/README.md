# Yellow Pine Brand — Identity v3 (August 2026)

The design home for the Yellow Pine identity. **Source of truth:** the public
`yellow-pine/.github` repo, `brand/` — these boards are generated mirrors
(`brand/design/` pipeline; edit masters there, rebuild, resync).

**Identity v3** — adopted in preproduction, derived from the brand premise alone (two
independent replicates, near-identical results): the name is the palette. Pine `#1C533D`
is the brand primary; wood gold `#AC8717` / `#F2CE59` is the mark ("Yellow" is literally
the gold tree between the words); paper `#F8F7F2` and forest ink `#121E17` are the
ground; pass/fail status reserved. Type: Literata 600 (lockup + display) · Source Sans 3
(body/UI) · JetBrains Mono (code/data — the products' own face). Mark geometry unchanged
from v2.1: one rounded two-tier pine at every size.

## Boards

- **Cover** — the lockup and the one-line system.
- **Main (Identity v3)** — lockups light/forest, the one-mark system, palette, rules.
- **Why it changed (MarkStory)** — the v1 → v2.1 mark evolution and candidate record.
- **Foundations** — type system, computed color contracts, the derivation story, and the
  v2-era selection history.
- **In situ (Applications)** — org profile, browser tabs, terminal.

The `cards/` here feed the org Design System pane. Full guideline (web + paper scales,
print rules, guardrails): `brand/README.md` in the repo.
