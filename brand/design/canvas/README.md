# Yellow Pine Brand — Identity v2.2 (August 2026)

The design home for the Yellow Pine identity. **Source of truth:** the public
`yellow-pine/.github` repo, `brand/` — these boards are generated mirrors
(`brand/design/` pipeline; edit masters there, rebuild, resync).

## Boards

- **Cover** — the lockup and the one-line system.
- **Main (Identity v2)** — lockups light/dark, the one-mark system (16px-proof), the
  four-hue palette, rules.
- **Why it changed (MarkStory)** — v1 → v2.1 mark evolution, four candidate directions,
  three-critic verdicts.
- **Foundations** — the face (Rubik 700, chosen four independent times incl. blind and
  menu-free derivation), computed color contracts, extended tokens, the palette-selection
  story, and the derivation record.
- **In situ (Applications)** — org profile, browser tabs, terminal.

## System in one breath

Mark: rounded two-tier pine, 4° lean, one geometry at every size. Face: Rubik 700
(+0.02em lockup tracking; headings neutral). Palette: four hues — Cyber Yellow `#FFD100`
(identity only), Eerie Black `#202020` / Baby Powder `#FCFCFC` / Jet `#333533` (neutrals),
Bleu de France `#3C91E6` (interactive, with derived link steps `#1a75c8` light /
`#82BCF2` dark). Print: `logo-mono.svg` for one-color, yellow as spot, brass `#7E6604`
for brand-hue text on light. The `cards/` here feed the org Design System pane.
